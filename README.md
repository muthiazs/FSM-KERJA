# FSM KERJA HTML Prototype

Prototype frontend-only untuk presentasi awal aplikasi FSM KERJA.

## Cara Menjalankan

1. Ekstrak folder ini.
2. Buka `index.html` di browser.
3. Gunakan dropdown **Role Switcher** di kanan atas untuk simulasi Dekan, Wakil Dekan, Kaprodi, Supervisor, Dosen, Staff, dan Admin.

## Fokus Prototype

- Monitoring dashboard role-based
- Memberi tugas
- Menerima dan mengerjakan tugas
- Membuat laporan kegiatan
- Katalog fleksibel: Indikator → Output → Kegiatan Claimable
- Admin katalog dengan penyimpanan dummy di `localStorage`
- Verifikasi sederhana
- Portofolio individu

## Catatan

- Belum menggunakan backend.
- Data dummy tersimpan di browser menggunakan `localStorage`.
- Upload file hanya mockup tampilan.
- Cocok untuk presentasi alur dan UI awal.
